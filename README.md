# 🛒 Cartway - Modern E-Commerce Platform



Cartway is a modern and responsive e-commerce frontend application built with **React**, **Redux Toolkit**, **Tailwind CSS**, and **DaisyUI**. It provides a smooth shopping experience with product browsing, category filtering, product details, cart management, and wishlist functionality.

🔗 **Live Demo:** [cartway-three.vercel.app](YOUR_LIVE_LINK_HERE)

---

## 📌 About The Project

Cartway is a frontend e-commerce application designed to simulate a real-world online shopping platform. The project focuses on building a scalable React architecture, managing global state efficiently, integrating APIs, and creating a modern responsive UI.

The application allows users to explore products, filter them by category, view product details, add items to cart, and save favorite products to their wishlist.

## 🔌 API Integration

Cartway uses the DummyJSON API to fetch product data.

**Get All Products**
```
https://dummyjson.com/products
```

**Get Products By Category**
```
https://dummyjson.com/products/category/{category}
```

---

## 🧠 Redux State Management

Cartway uses Redux Toolkit to manage application state.

### Redux Slices

- **Product Slice** — Stores product data fetched from API
- **Category Slice** — Handles category-based products
- **Cart Slice** — Manages cart items
- **Wishlist Slice** — Manages favorite products
